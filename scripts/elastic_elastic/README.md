# Elastic–elastic scenes

Scenes whose primary interaction is between two elastic bodies. There are 2;
`../scene_registry.json` is authoritative and each scene's README gives its physics, cases,
requirements and the commands that rebuild it.

- [`cotton_tshirt_sofa`](cotton_tshirt_sofa/README.md): A cotton T-shirt falls onto a sofa and folds over it.
- [`entryway_eva_slippers`](entryway_eva_slippers/README.md): An EVA slipper falls in an entryway onto the floor and the other slipper.
